# ボイス伝言メモ

音声で入力した伝言メモを保存し、まとめて要約できるウェブアプリです。

## 特徴

- **音声入力**: ブラウザ標準のWeb Speech APIを使用（無料・APIキー不要、Google Chrome推奨）
- **要約**: 外部APIを使わない完全無料のルールベース要約（文字bigramの頻度から重要な文を抽出）
- **保存先**: サーバー側の `data/messages.json` にメモを保存

## セットアップ

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## 使い方

1. 「🎤 録音開始」を押して話す（もう一度押すと録音停止）
2. 文字起こし結果はテキストエリアで編集できます
3. 「この内容を保存」で伝言として保存
4. 一覧からチェックボックスで対象を選び、「選択した伝言を要約する」を押す（何も選択しない場合は全件が対象）

## 注意事項

- 音声入力はGoogle Chromeなど一部ブラウザのみ対応です。対応していない場合はテキストを直接入力して保存できます。
- 要約はAIではなく簡易的なルールベース処理のため、文章の重要度判定の精度は高くありません。
